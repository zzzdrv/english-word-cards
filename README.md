# 英语单词卡

给初中生背英语单词的 Web 应用。基于间隔重复（Spaced Repetition）算法：会了的词隔越来越久再复习，不会的词第二天就回来、当场再学一遍。


## 快速上手（单机版）

1. 用 Chrome（或任何现代浏览器）打开 `英语单词卡.html`。
2. 首页点「开始今日学习」。
3. 数据保存在本机浏览器里，关掉重开都在。**注意**：不同浏览器、App 内嵌浏览器之间的数据不互通；清除浏览器数据会连进度一起清掉，重要进度记得先导出备份。
4. 安卓手机想像 App 一样用：Chrome 打开文件 → 右上角 ⋮ →「添加到主屏幕」。
5. 单词配图是网络图片，首次加载需要联网。

## 学习流程

- 卡片正面**只显示英文**，凭记忆判断：**会 / 跳过 / 不会**。
  - 「跳过」：不评分，直接过，不影响任何数据。
  - 「会」：展开自测区，再选「真会」或「记错了」。只有点「真会 / 不会 / 记错了」才会写入学习记录。
- 卡住了点「再看一个线索」，按顺序给出提示：**图片 → 助记 → 例句 → 释义**，能少看就少看。
- 「助记」是给每个词写的记忆口诀，可以自己改，改完自动保存。
- 一轮学完自动进入**测验**，优先考本轮记错 / 不会的词。
- 中途退出不用怕：每次评分后自动存断点，下次进学习页会提示「继续上次学习」。

## 记忆等级（L0–L5）

| 等级 | 含义 | 下次复习 |
|---|---|---|
| L0 | 未学 | — |
| L1 | 初识 | 1 天后 |
| L2 | 眼熟 | 3 天后 |
| L3 | 较熟 | 7 天后 |
| L4 | 掌握 | 15 天后 |
| L5 | 牢固 | 30–60 天后 |

- 点「真会」升 1 级，复习间隔按上表拉长；L4 及以上计为「已掌握」。
- 点「不会 / 记错了」降 2 级，第二天复习，并且**当场在队尾再出现一次**（立即重学）。
- 测验只影响复习顺序，不改变等级。

## 主要功能

- **今日学习**：每天的任务 = 到期复习 + 新词（数量在设置里调，默认每天 8 个新词）。
- **统计**：今日已学 / 总计已学 / 掌握率，数字都能点，点进去看是哪些词；分包进度支持两级下钻。
- **单词列表**：顶部 L0–L5 六张等级卡片点选筛选；支持中英文搜索；每行 5 个圆点直观显示等级。
- **难词本**：一个词累计记错 / 不会 3 次自动进入，可单独复习。
- **测验**：学习轮次结束后自动开始，靶向薄弱词。

## 备份、快照与数据管理（设置页）

- **导出备份**：把全部进度导出为 JSON 文件，换设备、重装前先导一份。
- **导入恢复**：按「按卡合并」恢复——只覆盖备份里有的卡，备份之后新学的词不受影响。
- **自动快照**：每天学完自动存一份；执行「全部初始化 / 按包重置 / 导入恢复」前也会自动存一份。只保留最近 3 份，可一键恢复或删除。
- **全部初始化**：清空所有进度、记录、助记、难词本（不可恢复，操作前先导出备份）。
- **按包重置**：只清空某一个词包的进度，其他包不动。

- 在应用内「导入词包」可追加新包，无需重新下载应用。
- 想自制词包，按下面的 JSON 格式准备即可：

```json
{
  "packId": "my-pack-1",
  "book": "自定义名称",
  "unit": "Unit 1",
  "version": "1.0",
  "cards": [
    {
      "id": "my-pack-1-0001",
      "en": "apple",
      "phonetic": "/ˈæpl/",
      "pos": "n.",
      "zh": "苹果",
      "examples": [{ "en": "I like apples.", "zh": "我喜欢苹果。" }],
      "image": "https://…（可省略）",
      "image_query": "red apple"
    }
  ]
}
```

字段说明：`en` 英文（必填）、`zh` 中文释义（必填）、`pos` 词性（必填）、`examples` 例句+翻译（必填，1 条即可）、`phonetic` 英式音标（词组可省略）、`image` 配图 URL（没有可省略，抽象词不建议硬配）、`image_query` 配图搜索关键词。

## 常见问题

- **首页单词总数和词包加总对不上？** 正常。首页是按英文去重的合并口径，跨包重复的词只算一次。
- **学过的词第二天又出现了？** 看它的等级：L1 的词就是设计为 1 天后复习的。只有 L4/L5 才会隔很久。
- **备份文件能在两个版本之间通用吗？** 备份恢复是「按卡合并」语义，词包一致的前提下可以互导。
